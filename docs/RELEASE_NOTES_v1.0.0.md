# Đảo Đèn Lồng v1.0.0 — "Bình minh"

Game 3D 3 Đêm (Đảo Bến, Đảo Cau, Đảo Chuông): thắp và giữ đèn sáng tới bình minh. Test Contract v1.3.

## Chạy
- **Bản web tĩnh:** tải `dao-den-long-web-v1.0.0.zip`, giải nén, `python3 -m http.server 8080` trong thư mục, mở http://localhost:8080 (hướng dẫn trong `CHAY-GAME.txt`).
- **Đầy đủ (bảng xếp hạng lưu đĩa, headless, bench, soak):** clone repo → `npm run build` → `npm start` (Node ≥ 22.18, không cần npm install).

## Có gì
3 Đêm, lướt, Gió Lạc, Bùa Gió, đèn cạn dầu, bảng xếp hạng top 10, đổi phím, phụ đề, giảm chuyển động, chữ lớn, bảng màu dễ phân biệt, benchmark + soak. Chi tiết: CHANGELOG.md.

## Bằng chứng
`docs/proof/phase-1..4/` (traceability, verify-report), `soak.json`, `bench.json`. Video demo: `demo.mp4` đính kèm Release này.
